# Clone Lipglues Maxwell

A fully functional, independent frontend clone with a custom Supabase backend and Admin Dashboard.

### Features
- **Frontend**: Plain HTML5/CSS/JS frontend restored to work independently of the original Firebase infrastructure.
- **Backend**: Supabase PostgreSQL database (7 tables) with full Row-Level Security (RLS).
- **Admin Dashboard**: Custom-built dashboard (`/admin`) for full CRUD management of products, CMS content, store locations, and subscribers.
- **Analytics**: Custom, privacy-respecting event tracking integrated directly into the Supabase database.
